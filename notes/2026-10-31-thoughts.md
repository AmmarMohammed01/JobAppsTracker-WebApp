"when to use flex vs grid"
- https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Grid_layout/Relationship_with_other_layout_methods 
- flexbox for one-dimension layouts (single row or column)
- grid for two dimensional layout (rows and columns at the same time)

```CSS
nav {display: flex;}
/* Both of these get equal amount of flexible space*/
nav h1 {flex: 1;} 
nav ul {flex: 1;}

.box {display: flex;}
/* h1 element gets 2 times the space of the ul element */
.box h1 {flex: 2;} 
.box ul {flex: 1;}
```
