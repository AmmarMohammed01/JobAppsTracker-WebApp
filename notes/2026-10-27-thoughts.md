How to delete column in SQLite
- not update, drop
- use alter
    - ALTER TABLE resume DROP COLUMN resume_link;

PLAN
- create new table
- transfer old table's contents
- drop old table
- rename new table to old table name

```sql
sqlite> .schema resume
CREATE TABLE resume (
  resume_id   INTEGER PRIMARY KEY AUTOINCREMENT,
  resume_name TEXT UNIQUE COLLATE NOCASE,
  resume_link TEXT UNIQUE COLLATE NOCASE
);
```

```sql
sqlite> SELECT * FROM resume;
1|swe res|
2|ceo res|
3|hwe res|
4|leaf res|
5|animator res|
6|artist res|
7|cooked res|
8|bioengineering|
9|gui res|

```

```sql
CREATE TABLE resume_new (resume_id INTEGER PRIMARY KEY AUTOINCREMENT, resume_name TEXT UNIQUE COLLATE NOCASE);
```

```sql
INSERT INTO resume_new (resume_id, resume_name)
SELECT resume_id, resume_name
FROM resume;
```

```sql
sqlite> select * from resume_new;
1|swe res
2|ceo res
3|hwe res
4|leaf res
5|animator res
6|artist res
7|cooked res
8|bioengineering
9|gui res
10|web res
```

```sql
DROP TABLE resume;
```

```sql
ALTER TABLE resume_new
RENAME TO resume;
```
